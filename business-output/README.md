# 文档说明

## 去敏化处理说明

本文档集是将原始PHS-HIS接口文档进行去敏化处理后生成的对外展示材料。

### 去敏化内容

| 类型 | 处理方式 |
|------|----------|
| 公司名称 | 替换为"智慧医疗服务平台" |
| 内部编号 | 移除或替换为通用描述 |
| 具体医院名称 | 替换为通用描述 |
| 系统内部代号 | 替换为通用名称 |
| 接口路径 | 保留功能描述，移除具体路径 |
| 技术细节 | 保留能力描述，移除实现细节 |

### 保留内容

- 接口功能描述
- 业务流程说明
- 业务价值阐述
- 技术架构能力
- 接口数量统计
- 功能模块分类
