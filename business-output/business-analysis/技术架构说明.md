### 2.2 接口设计规范

#### RESTful设计原则
```
GET    /api/v1/patients          # 查询患者列表
GET    /api/v1/patients/{id}     # 查询患者详情
POST   /api/v1/patients          # 创建患者档案
PUT    /api/v1/patients/{id}     # 更新患者信息
DELETE /api/v1/patients/{id}     # 删除患者档案
```

#### 统一响应格式
```json
{
  "code": "0000",
  "message": "操作成功",
  "data": {},
  "timestamp": 1700000000000,
  "requestId": "req_xxxxxxxx"
}
```

#### 错误码规范
| 错误码 | 说明 |
|--------|------|
| 0000 | 成功 |
| 1001 | 参数错误 |
| 1002 | 认证失败 |
| 1003 | 权限不足 |
| 2001 | 业务错误 |
| 5001 | 系统错误 |

### 4.2 数据同步机制

| 同步类型 | 说明 | 实现方式 |
|----------|------|----------|
| **实时同步** | 关键数据即时同步 | 接口实时调用 |
