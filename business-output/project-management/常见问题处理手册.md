# 智慧医疗平台 - 常见问题处理手册

> 基于实际客服经验整理的问题处理方案

---

## 手册说明

本文档整理了智慧医疗平台实际运营中最常见的问题及处理方案，涵盖：
- **高频问题**：用户最常咨询的业务问题
- **技术问题**：系统功能异常类问题

## 一、高频问题处理

### 问题1: 如何预约检查

**问题描述**: 患者不知道如何在小程序预约检查项目

**问题分析**: 
- 用户对线上预约流程不熟悉
- 部分检查项目需要医生先开单
- 不同医院的预约流程存在差异

**处理方案**:
```
客服回复:
"检查预约需要先到门诊挂号或点击互联网医院在线问诊找医生开单。

预约流程:
1. 点击小程序首页【预约挂号】
2. 选择【检查预约】科室
3. 选择检查项目和时间段
4. 确认预约并支付（如需）

温馨提示:
• 部分检查项目需要医生开具检查单后才能预约
• 可预约未来14天内的检查
• 预约成功后请按时前往检查"
```

**优化建议**:
- 首页增加【检查预约】快捷入口
- 优化预约流程引导
- 增加检查项目说明（是否需要先开单）

---

### 问题2: 咨询院内就诊流程

**问题描述**: 患者不清楚线上预约后的就诊流程

**问题分析**:
- 线上线下流程存在差异
- 不同医院流程不同
- 首次使用线上服务的患者不熟悉

**处理方案**:
```
客服回复:
"您好，在线客服仅提供软件咨询，就诊流程咨询及投诉等请点击小程序【便民服务】-【服务电话】联系医院相关部门。

一般就诊流程:
线上预约 → 就诊当天到医院 → 自助机/窗口取号 → 候诊 → 就诊

温馨提示:
• 请提前30分钟到达医院
• 携带身份证和医保卡
• 初次就诊请先建立就诊档案"
```

**优化建议**:
- 增加【就诊指南】功能模块
- 提供医院导航和科室分布图
- 制作就诊流程短视频

---

### 问题3: 如何复诊开单

**问题描述**: 复诊患者需要开具检查/药品处方

**问题分析**:
- 复诊流程与初诊不同
- 部分医院支持在线复诊开单
- 用户不清楚哪些项目可以线上开

**处理方案**:
```
客服回复:
"请点击小程序首页【互联网医院】-【复诊续方】联系医生开单。

支持线上开单的项目:
• 常规检查检验（血常规、尿常规等）
• 慢病用药续方
• 部分专科复诊

注意事项:
• 需要历史就诊记录
• 部分项目仍需线下开单
• 开单后需在线支付"
```

### 问题4: 个别报告查询无法查看具体报告

**问题描述**: 用户点击报告查询，但无法查看详细内容

**问题分析**:
- 网络环境异常
- 报告尚未完成对接
- 权限问题

**处理方案**:
```
客服回复:
"非常抱歉，尚在对接中暂未上线，我们会尽快上线。

临时解决方案:
1. 检查网络连接是否正常
2. 尝试刷新页面
3. 如仍无法查看，请到医院窗口或自助机打印

我们会尽快完成系统对接，感谢您的理解！"
```

**技术说明**:
```
根因分析:
• 医院PACS/LIS系统尚未完成对接
• 接口调试中
• 数据同步延迟

处理状态: 已反馈技术团队，推进对接中
```

## 二、技术问题处理

### 问题5: 绑定就诊人时，无法获取短信验证码

**问题描述**: 用户绑定就诊人时收不到验证码

**问题分析**:
- 短信通道限制（同一手机号每天限制5条）
- 手机拦截软件拦截
- 网络延迟

**处理方案**:
```
客服回复:
"1、通讯正常情况下，一个手机号每天仅能获取5条短信验证码，超过次数无法获取。

解决方案:
1. 请确认手机号输入正确
2. 检查是否被手机拦截软件拦截
3. 等待24小时后重试
4. 如仍无法获取，请使用【语音验证码】"
```

**优化建议**:
- 增加语音验证码备选方案
- 优化验证码获取频次提示
- 增加验证码有效期说明

---

### 问题6: 当天的号怎么取消

**问题描述**: 用户需要取消当天已预约的号

**问题分析**:
- 医院规定当天号不能线上取消
- 部分医院支持线上退号
- 用户不清楚退号规则

**处理方案**:
```
客服回复:
"根据医院管理要求，当天的号只能当天到医院窗口取消，线上无法取消预约。

退号规则:
• 当天号源：需到医院窗口办理
• 非当天号源：可在小程序【我的挂号】中取消
• 超过就诊时间视为爽约

建议:
如无法前往就诊，请尽早到医院窗口办理退号，以免影响后续预约。"
```

---

### 问题7: 小程序个别功能点击无响应

**问题描述**: 用户点击某些功能按钮没有反应

**问题分析**:
- 微信小程序缓存问题
- 版本兼容性问题
- 网络问题

**处理方案**:
```
客服回复:
"1.微信小程序下拉聊天框，长按移除小程序，重新搜索进入。
2.支付宝小程序找到【我的小程序】模块，点击进入，长按移除小程序，重新搜索进入。

原因说明:
• 微信版本兼容性问题或网络问题
• 小程序缓存导致功能异常

如仍无法解决，请提供:
• 手机型号和微信版本
• 问题截图
• 操作步骤

我们会安排技术工程师跟进处理。"
```

---

### 问题8: 点击取消预约按钮或其它操作无反应

**问题描述**: 用户点击按钮无响应

**问题分析**:
- 微信版本兼容性问题
- 网络环境问题

**处理方案**:
```
客服回复:
"类似问题可以让用户，下拉微信聊天框，长按移除小程序然后重新搜索使用即可。

原因说明:
• 微信版本兼容性问题或网络问题
• 建议更新微信到最新版本"
```

---

### 问题9: 用户问题描述不清楚或需要用户提供截图佐证

**处理方案**:
```
客服回复:
"请用户通过我院微信小程序-【我的】-【软件使用咨询】-【在线客服】提供相关截图，注意直...

用户提交截图后在联络群里通知和仁工程师介入查看"
```

**处理流程**:
1. 引导用户提供问题截图
2. 收集用户基本信息（手机型号、微信版本）
3. 在技术群里@工程师跟进
4. 工程师分析后反馈解决方案
5. 客服回访用户确认问题解决

### 问题10: 修改登录手机号

**处理方案**:
```
客服回复:
"就诊人手机号更换是在家庭成员里修改，登陆手机号在小程序里退出登陆切换。"

操作步骤:
1. 修改就诊人手机号:
   【我的】→【家庭成员】→选择就诊人→修改手机号

2. 修改登录手机号:
   【我的】→【设置】→【退出登录】→用新手机号登录"
```

---

### 问题11: 互联网医院医生问诊以后医生没时间回复

**问题描述**: 医生超时未回复问诊消息

**处理方案**:
```
客服回复:
"医生超时一句都没回复会自动取消订单，问诊结束后医生无法再回复。

温馨提示:
• 医生会在24小时内回复
• 如医生未回复，订单会自动取消，费用原路退回
• 建议重新发起问诊或选择其他医生"
```

## 三、低频问题处理

### 问题12: 为什么提示"当前账号累计绑定人数超过限制，无法操作"?

**问题分析**: 系统限制防止恶意注册

**处理方案**:
```
客服回复:
"目前服务就诊人绑定限制如下:
1.72小时内新增或删除次数限制3次，超过次数会触发限制
2.同一身份证最多绑定3个账号
3.如有特殊情况，请联系客服处理"
```

---

### 问题13: 放号时间是什么时候?

**处理方案**:
```
客服回复:
"患者可查看14天的排班，下午3点放号，即下午3点后可查看第15天的排班进行预约。

放号规则:
• 每天下午3:00放第15天的号
• 可预约未来14天内的号源
• 部分热门号源可能很快被约满"
```

---

### 问题14: 挂号科室列表无法加载

**处理方案**:
```
客服回复:
"打开手机飞行模式然后再恢复，重新进入下小程序。

原因说明:
• 网络环境异常导致的
• 飞行模式重置网络连接"
```

---

### 问题15: 门诊缴费支付单边

**问题描述**: 支付成功但系统未收到回调

**处理方案**:
```
客服回复:
"单边费用30分钟内原路退回，再引导患者通过其它方式缴费。

需查看支付账单详情，明确是通过小程序渠道支付的。

说明:
• 单边是指支付成功但HIS系统未收到支付结果
• 系统会自动发起退款
• 请稍后重新支付"
```

---

### 问题16: 预交金缴费支付单边

**处理方案**:
```
客服回复:

说明:
• 住院预交金金额偏大，不做自动退费
• 窗口不方便时反馈给信息科，通过后台处理"
```

## 四、问题处理规范

### 4.1 响应时效要求

| 问题级别 | 响应时间 | 解决时间 | 示例 |
|---------|---------|---------|------|
| **紧急** | 5分钟内 | 2小时内 | 系统故障、支付异常 |
| **高** | 15分钟内 | 4小时内 | 功能无法使用、数据错误 |
| **中** | 30分钟内 | 24小时内 | 体验问题、咨询类 |
| **低** | 2小时内 | 72小时内 | 优化建议、一般咨询 |

### 4.2 处理流程

```
问题接收 → 初步判断 → 方案回复 → 跟进确认 → 归档总结
    ↑                                    ↓
    └──────────── 转技术/产品 ───────────┘
```

### 4.3 升级机制

```
客服处理 ──▶ 无法解决 ──▶ 转技术群
    │                       │
    │                       ▼
    │                   工程师分析
    │                       │
    │           ┌───────────┴───────────┐
    │           ▼                       ▼
    │       配置问题               代码Bug
    │           │                       │
    │           ▼                       ▼
    │       配置修改               修复上线
    │           │                       │
    └───────────┴───────────┬───────────┘
                            ▼
                        客服回访
                            │
                            ▼
                        问题关闭
```
