# 智慧医疗服务平台 - 业务案例

## 案例一：患者在线建档与身份认证

### 业务场景
患者首次使用智慧医疗服务平台，需要完成在线建档，建立院内就诊档案。

### 涉及接口功能
1. **档案查询功能**：根据患者提供的身份信息（身份证、护照、港澳台通行证等），查询院内是否已有建档记录
2. **在线建档功能**：为未建档患者创建院内就诊档案，包含基本信息、证件信息、联系方式
3. **档案更新功能**：允许患者更新档案信息，如修改手机号
4. **电子健康卡功能**：为患者申领电子健康卡，并与院内档案绑定
5. **身份认证功能**：验证患者身份真实性，支持免密签约简化后续操作

### 业务流程
```
患者打开小程序 → 输入身份信息 → 系统查询档案 → 
（无档案）→ 在线建档 → 申领电子健康卡 → 建档完成
（有档案）→ 身份认证 → 绑定电子健康卡 → 建档完成
```

### 业务价值
- 患者无需到医院窗口排队建档，节省时间
- 一次建档，全院通用，避免重复建档
- 电子健康卡替代实体卡，便捷环保

## 案例二：预约挂号全流程

### 业务场景
患者需要预约某科室医生的门诊号源。

### 涉及接口功能
1. **院区查询功能**：查询医院各院区信息
2. **科室查询功能**：按院区查询科室列表，支持多级目录展示
3. **医生查询功能**：按科室查询医生信息
4. **排班查询功能**：查询医生的出诊排班安排
5. **号源查询功能**：查询指定时段的可预约号源
6. **预约锁号功能**：锁定选中的号源，防止被他人预约
7. **正式挂号功能**：支付完成后确认挂号
8. **取消预约功能**：支持患者主动取消预约或超时自动取消
9. **状态通知功能**：挂号状态变更时主动通知（停诊、待就诊、已就诊）

### 业务流程
```
选择院区 → 选择科室 → 查看医生排班 → 选择时段 → 
预约锁号 → 确认支付 → 正式挂号 → 挂号成功 → 就诊提醒
```

### 业务价值
- 分时段精准预约，减少现场等待时间
- 实时号源同步，防止超售
- 多渠道预约统一管理，避免重复预约

## 案例三：智能导诊与预问诊

### 业务场景
患者不确定应该挂哪个科室，希望系统根据症状推荐合适的科室和医生。

### 涉及接口功能
1. **智能导诊功能**：根据患者输入的症状、疾病关键词，推荐合适的科室和医生
2. **预问诊功能**：预约挂号成功后，患者在线填写预问诊问卷
3. **病史推送功能**：将患者填写的预问诊信息推送给接诊医生
4. **问卷查询功能**：医生可查看患者的历史预问诊记录

### 业务流程
```
输入症状 → 系统推荐科室医生 → 完成预约 → 
填写预问诊问卷 → 问卷信息推送医生 → 医生查看病史 → 开始诊疗
```

### 业务价值
- 帮助患者精准选择科室，避免挂错号
- 提前收集病史，提升诊疗效率
- 减少医患沟通时间成本

## 案例四：门诊费用在线支付

### 业务场景
患者就诊后需要缴纳门诊费用（药品费、检查费、治疗费等）。

### 涉及接口功能
1. **费用列表查询功能**：查询患者待缴费项目列表，按就诊记录分组展示
2. **费用明细查询功能**：查询费用明细，包括费用类型、处方明细等
3. **在线支付功能**：支持多种支付方式完成在线支付
4. **支付通知功能**：支付完成后将支付结果通知医院系统
5. **支付状态查询功能**：查询支付订单状态，异常时自动处理
6. **医保结算功能**：支持医保患者在线进行医保结算
7. **退费功能**：支持窗口退费，金额原路返回

### 业务流程
```
查看待缴费 → 查看费用明细 → 确认支付 → 
支付成功 → 通知医院系统 → 缴费完成 → 取药/检查
```

### 业务价值
- 先诊疗后付费，优化就医体验
- 移动支付减少排队时间
- 医保在线结算，无需窗口报销

---

## 案例五：检验检查报告查询

### 业务场景
患者完成检验或检查后，需要查询报告结果。

### 涉及接口功能
1. **检验报告列表功能**：查询一段时间内的检验项目列表
2. **检验报告详情功能**：查询检验报告详情，包括项目、结果、参考范围、异常标识
3. **检查报告列表功能**：查询一段时间内的检查项目列表（CT、X光、B超等）
4. **检查报告详情功能**：查询检查报告详情，包括影像所见、诊断建议
5. **云影像服务功能**：支持影像在线查看，可生成PDF报告
6. **影像支付功能**：云影像服务在线支付

### 业务流程
```
完成检查 → 等待报告 → 报告生成通知 → 
查看报告列表 → 查看报告详情 → 下载PDF报告 → 云影像查看
```

### 业务价值
- 患者随时查看报告，无需到医院取报告
- 减少医院报告打印成本
- 历史报告可追溯，便于复诊

## 案例七：住院费用管理

### 业务场景
住院患者需要查询住院信息、缴纳预交金、查看费用清单。

### 涉及接口功能
1. **住院信息查询功能**：查询患者当前住院信息，包括病区、床位、余额
2. **预交金充值功能**：在线预交金充值，充值信息通知医院系统
3. **缴费记录查询功能**：查询历次预交金充值记录
4. **费用清单查询功能**：查询每日费用清单或历次住院费用清单
5. **费用明细查询功能**：查询费用清单明细
6. **出院预结算功能**：出院前进行费用预结算
7. **正式结算功能**：出院时进行正式结算
8. **退费功能**：出院后窗口退费

### 业务流程
```
查询住院信息 → 在线充值预交金 → 查看每日费用 → 
出院预结算 → 正式结算 → 出院
```

### 业务价值
- 住院费用透明可查
- 在线充值，无需往返
- 出院结算更高效
