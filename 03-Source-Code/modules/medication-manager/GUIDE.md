# 用药管理模块 - 业务流程详解

## 📖 文档说明

本文档详细讲解用药管理模块的业务流程，通过具体的使用场景帮助理解代码功能。

---

## 👤 用户角色

- **患者/用户**：使用用药提醒功能管理日常用药
- **系统**：后台配置管理功能开关

## 🔍 常见问题排查

### Q1: 列表不显示数据

**排查步骤：**
1. 检查 `onShow` 生命周期是否执行
2. 检查 `getList()` 是否被调用
3. 检查 API 返回的数据结构是否正确
4. 检查 `medicalList` 是否被正确赋值

### Q2: 编辑时表单没有填充数据

**排查步骤：**
1. 检查列表页是否正确调用了 `medicationStore.updateCheckItem(item)`
2. 检查表单页的 `onShow` 是否正确检测到 `medicationStore.checkItem`
3. 检查 `assignFromMedication` 是否正确执行
4. 检查填充后是否正确清空了 `checkItem`

### Q3: 从历史处方导入后没有预填充

**排查步骤：**
1. 检查历史处方页是否正确调用了 `medicationStore.changeAddItem(drug)`
2. 检查表单页是否正确检测到 `medicationStore.addItem`
3. 检查 `extractDrugDetailToForm` 是否正确提取字段
4. 检查中药和西药的提取逻辑是否正确区分

### Q4: 提醒时间添加失败

**排查步骤：**
1. 检查 `addNotifyTime` 是否正确调用
2. 检查时间是否已存在（避免重复）
3. 检查 `form.notifyTime` 数组是否正确更新
