# 智慧医疗服务平台 - 设计模式分析

## 一、Adapter（适配器）模式

### 1.1 模式概述

Adapter模式用于将一个类的接口转换成客户希望的另外一个接口，使得原本由于接口不兼容而不能一起工作的那些类可以一起工作。

### 1.2 应用场景

在智慧医疗服务平台中，需要对接多家医院的HIS系统，每家医院的接口协议、数据格式、字段定义都可能不同。Adapter模式用于统一这些差异。

## 二、State Machine（状态机）模式

### 2.1 模式概述

状态机模式用于管理对象在其生命周期内所经历的各种状态以及状态之间的转换规则。

### 2.2 应用场景

在智慧医疗服务平台中，多个业务流程涉及状态管理：
- 预约挂号状态流转
- 支付订单状态流转
- 挂号订单状态流转
- 住院状态流转

### 2.5 代码示例

```java
// 状态接口
public interface OrderState {
    void handle(OrderContext context, OrderEvent event);
    OrderStatus getStatus();
}

// 具体状态：待支付
public class PendingPaymentState implements OrderState {
    @Override
    public void handle(OrderContext context, OrderEvent event) {
        switch (event) {
            case PAY:
                context.setState(new PayingState());
                context.doPay();
                break;
            case CANCEL:
                context.setState(new CancelledState());
                context.doCancel();
                break;
            default:
                throw new IllegalStateException();
        }
    }
    
    @Override
    public OrderStatus getStatus() {
        return OrderStatus.PENDING_PAYMENT;
    }
}

// 具体状态：支付中
public class PayingState implements OrderState {
    @Override
    public void handle(OrderContext context, OrderEvent event) {
        switch (event) {
            case PAY_SUCCESS:
                context.setState(new PaidState());
                context.doNotifyHIS();
                break;
            case PAY_FAIL:
                context.setState(new PayFailedState());
                context.doFail();
                break;
            default:
                throw new IllegalStateException();
        }
    }
    
    @Override
    public OrderStatus getStatus() {
        return OrderStatus.PAYING;
    }
}

// 具体状态：已支付
public class PaidState implements OrderState {
    @Override
    public void handle(OrderContext context, OrderEvent event) {
        switch (event) {
            case NOTIFY_SUCCESS:
                context.setState(new CompletedState());
                context.doComplete();
                break;
            case NOTIFY_FAIL:
                context.setState(new NotifyExceptionState());
                context.doRetry();
                break;
            default:
                throw new IllegalStateException();
        }
    }
    
    @Override
    public OrderStatus getStatus() {
        return OrderStatus.PAID;
    }
}

// 上下文
public class OrderContext {
    private OrderState state;
    private Order order;
    
    public void setState(OrderState state) {
        this.state = state;
        this.order.setStatus(state.getStatus());
    }
    
    public void handle(OrderEvent event) {
        state.handle(this, event);
    }
    
    // 业务方法
    public void doPay() { /* 执行支付 */ }
    public void doCancel() { /* 执行取消 */ }
    public void doNotifyHIS() { /* 通知HIS */ }
    public void doComplete() { /* 完成订单 */ }
    public void doFail() { /* 处理失败 */ }
    public void doRetry() { /* 重试通知 */ }
}

// 使用示例
public class OrderService {
    public void processPayment(String orderId, PaymentResult result) {
        OrderContext context = getOrderContext(orderId);
        
        if (result.isSuccess()) {
            context.handle(OrderEvent.PAY_SUCCESS);
        } else {
            context.handle(OrderEvent.PAY_FAIL);
        }
    }
}
```

## 三、容错处理模式

### 3.1 重试模式（Retry Pattern）

#### 应用场景
- 网络抖动导致的接口调用失败
- HIS系统短暂不可用
- 第三方支付接口超时

#### 实现策略

```java
// 重试策略接口
public interface RetryPolicy {
    boolean shouldRetry(int attemptCount, Throwable error);
    long getDelay(int attemptCount);
}

// 指数退避策略
public class ExponentialBackoffPolicy implements RetryPolicy {
    private final int maxAttempts;
    private final long initialDelay;
    private final double multiplier;
    
    @Override
    public boolean shouldRetry(int attemptCount, Throwable error) {
        return attemptCount < maxAttempts && isRetryable(error);
    }
    
    @Override
    public long getDelay(int attemptCount) {
        return (long) (initialDelay * Math.pow(multiplier, attemptCount - 1));
    }
    
    private boolean isRetryable(Throwable error) {
        return error instanceof TimeoutException 
            || error instanceof ConnectException
            || error instanceof SocketTimeoutException;
    }
}

// 重试执行器
public class RetryExecutor {
    public <T> T execute(RetryPolicy policy, Callable<T> action) throws Exception {
        int attempt = 0;
        Exception lastException = null;
        
        while (policy.shouldRetry(attempt, lastException)) {
            try {
                return action.call();
            } catch (Exception e) {
                lastException = e;
                attempt++;
                
                if (policy.shouldRetry(attempt, e)) {
                    Thread.sleep(policy.getDelay(attempt));
                }
            }
        }
        
        throw lastException;
    }
}

// 使用示例
public class PaymentService {
    private RetryExecutor retryExecutor = new RetryExecutor();
    private RetryPolicy retryPolicy = new ExponentialBackoffPolicy(3, 1000, 2.0);
    
    public PaymentResult processPayment(PaymentRequest request) {
        return retryExecutor.execute(retryPolicy, () -> {
            return callPaymentGateway(request);
        });
    }
}
```

### 3.2 熔断器模式（Circuit Breaker）

#### 应用场景
- HIS系统长时间不可用
- 第三方服务故障
- 防止故障扩散

#### 状态流转

```
┌─────────────────────────────────────────────────────────────────┐
│                      熔断器状态流转                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌─────────┐    失败阈值      ┌─────────┐                     │
│   │  关闭   │ ────────────────│  打开   │                     │
│   │ (CLOSED)│                  │ (OPEN)  │                     │
│   └────┬────┘                  └────┬────┘                     │
│        │                            │                          │
│        │ 成功                        │ 超时                     │
│        │                            ▼                          │
│        │                       ┌─────────┐                     │
│        │                       │  半开   │                     │
│        └──────────────────────│ (HALF_OPEN)                    │
│              成功               └─────────┘                     │
│                                                                 │
│   状态说明：                                                     │
│   • 关闭：正常处理请求，记录失败次数                             │
│   • 打开：拒绝请求，直接返回错误                                 │
│   • 半开：允许部分请求试探服务恢复情况                           │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 代码示例

```java
// 熔断器状态
public enum CircuitBreakerState {
    CLOSED, OPEN, HALF_OPEN
}

// 熔断器
public class CircuitBreaker {
    private final int failureThreshold;
    private final long timeout;
    private final int halfOpenMaxCalls;
    
    private AtomicInteger failureCount = new AtomicInteger(0);
    private AtomicInteger successCount = new AtomicInteger(0);
    private AtomicInteger halfOpenCalls = new AtomicInteger(0);
    private volatile CircuitBreakerState state = CircuitBreakerState.CLOSED;
    private volatile long lastFailureTime = 0;
    
    public <T> T execute(Callable<T> action) throws Exception {
        if (state == CircuitBreakerState.OPEN) {
            if (System.currentTimeMillis() - lastFailureTime > timeout) {
                state = CircuitBreakerState.HALF_OPEN;
                halfOpenCalls.set(0);
            } else {
                throw new CircuitBreakerOpenException();
            }
        }
        
        if (state == CircuitBreakerState.HALF_OPEN) {
            if (halfOpenCalls.incrementAndGet() > halfOpenMaxCalls) {
                throw new CircuitBreakerOpenException();
            }
        }
        
        try {
            T result = action.call();
            onSuccess();
            return result;
        } catch (Exception e) {
            onFailure();
            throw e;
        }
    }
    
    private void onSuccess() {
        failureCount.set(0);
        
        if (state == CircuitBreakerState.HALF_OPEN) {
            successCount.incrementAndGet();
            if (successCount.get() >= halfOpenMaxCalls) {
                state = CircuitBreakerState.CLOSED;
                successCount.set(0);
            }
        }
    }
    
    private void onFailure() {
        failureCount.incrementAndGet();
        lastFailureTime = System.currentTimeMillis();
        
        if (state == CircuitBreakerState.HALF_OPEN) {
            state = CircuitBreakerState.OPEN;
        } else if (failureCount.get() >= failureThreshold) {
            state = CircuitBreakerState.OPEN;
        }
    }
}

// 使用示例
public class HISClient {
    private CircuitBreaker circuitBreaker = new CircuitBreaker(5, 60000, 3);
    
    public PatientInfo getPatientInfo(String idCard) {
        return circuitBreaker.execute(() -> {
            return callHIS(idCard);
        });
    }
}
```

### 3.3 降级模式（Fallback）

#### 应用场景
- 主服务不可用时提供备用方案
- 非核心功能失败时不影响主流程
- 提供缓存数据作为降级

#### 代码示例

```java
// 降级策略接口
public interface FallbackStrategy<T> {
    T fallback(Throwable error);
}

// 缓存降级
public class CacheFallbackStrategy<T> implements FallbackStrategy<T> {
    private Cache<String, T> cache;
    private String cacheKey;
    
    @Override
    public T fallback(Throwable error) {
        T cached = cache.get(cacheKey);
        if (cached != null) {
            return cached;
        }
        throw new FallbackFailedException();
    }
}

// 默认值降级
public class DefaultValueFallbackStrategy<T> implements FallbackStrategy<T> {
    private T defaultValue;
    
    @Override
    public T fallback(Throwable error) {
        return defaultValue;
    }
}

// 降级执行器
public class FallbackExecutor {
    public <T> T execute(Callable<T> action, FallbackStrategy<T> fallback) {
        try {
            return action.call();
        } catch (Exception e) {
            return fallback.fallback(e);
        }
    }
}

// 使用示例
public class ReportService {
    private FallbackExecutor fallbackExecutor = new FallbackExecutor();
    
    public ReportList getReportList(String patientId) {
        return fallbackExecutor.execute(
            () -> callHISForReports(patientId),
            new CacheFallbackStrategy<>(reportCache, patientId)
        );
    }
    
    public HospitalInfo getHospitalInfo() {
        return fallbackExecutor.execute(
            () -> callHISForHospitalInfo(),
            new DefaultValueFallbackStrategy<>(defaultHospitalInfo)
        );
    }
}
```

#### 代码示例

```java
// 超时控制执行器
public class TimeoutExecutor {
    private final ExecutorService executor;
    private final long timeout;
    private final TimeUnit timeUnit;
    
    public <T> T execute(Callable<T> action) throws TimeoutException {
        Future<T> future = executor.submit(action);
        try {
            return future.get(timeout, timeUnit);
        } catch (InterruptedException | ExecutionException e) {
            future.cancel(true);
            throw new RuntimeException(e);
        }
    }
}

// 使用示例
public class AppointmentService {
    private TimeoutExecutor timeoutExecutor = 
        new TimeoutExecutor(Executors.newFixedThreadPool(10), 5, TimeUnit.SECONDS);
    
    public AppointmentResult lockAppointment(LockRequest request) {
        try {
            return timeoutExecutor.execute(() -> {
                return callHISForLock(request);
            });
        } catch (TimeoutException e) {
            // 超时处理：释放锁、记录日志、返回错误
            releaseLock(request);
            throw new AppointmentLockTimeoutException();
        }
    }
}
```

```java
public class SMSNotificationObserver implements OrderObserver {
    @Override
    public void onOrderStatusChanged(Order order) {
        // 发送短信通知
        sendSMS(order);
    }
}
```

### 4.3 模板方法模式（Template Method）

用于统一接口调用流程：

```java
public abstract class AbstractHISOperation<T> {
    
    public final T execute(Request request) {
        // 1. 参数校验
        validate(request);
        
        // 2. 构建请求
        Object hisRequest = buildRequest(request);
        
        // 3. 调用HIS（子类实现）
        Object hisResponse = callHIS(hisRequest);
        
        // 4. 解析响应
        T result = parseResponse(hisResponse);
        
        // 5. 记录日志
        logOperation(request, result);
        
        return result;
    }
    
    protected abstract void validate(Request request);
    protected abstract Object buildRequest(Request request);
    protected abstract Object callHIS(Object request);
    protected abstract T parseResponse(Object response);
    protected abstract void logOperation(Request request, T result);
}
```

## 五、设计模式总结

| 模式 | 应用场景 | 解决的问题 |
|------|----------|-----------|
| **Adapter** | 多医院HIS对接 | 接口不兼容 |
| **State Machine** | 订单状态管理 | 状态流转复杂 |
| **Retry** | 网络抖动、服务短暂不可用 | 临时故障恢复 |
| **Circuit Breaker** | 服务长时间不可用 | 故障扩散防护 |
| **Fallback** | 服务降级 | 用户体验保障 |
| **Timeout** | 接口调用超时 | 资源占用问题 |
| **Factory** | 适配器创建 | 对象创建解耦 |
| **Observer** | 状态通知 | 一对多通知 |
| **Template Method** | 接口调用流程 | 代码复用 |
