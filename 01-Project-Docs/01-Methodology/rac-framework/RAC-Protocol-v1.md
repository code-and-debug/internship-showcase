> **进阶版** | 在 [RAC-FLOW基础版](./RAC-FLOW.md) 之上，增加严格性机制和边界警示

## 一、AI边界警示

AI存在以下结构性缺陷，使用时需保持警惕：

| 缺陷 | 表现 | 应对策略 |
|------|------|----------|
| **谄媚对齐** | 为最大化"人类满意度"而非"认知准确性" | 使用去讨好化协议（见第三节） |
| **水平迁移断裂** | 只能近缘推荐，无法跨域映射 | 强制使用解构矩阵（Step 2） |
| **元认知盲区** | 不知道自己不知道 | 要求AI声明置信度和盲区（Step 1） |
| **具象化反向缺失** | 能写PRD但无法从经历抽象方法论 | 使用极端约束（Step 4） |

**红旗信号**（看到即需重试）：
- "这是一个很有趣的..."
- "从某种角度来看..."
- "既...又..."（和稀泥）
- "我理解你的感受..."（过度共情）

## 二、RAC-FLOW 五步核心（简要）

完整版见 [RAC-FLOW.md](./RAC-FLOW.md)，此处仅列核心要点：

### Step 1: 元认知注入
让AI先建立思考框架，明确认知维度和抽象层级。

### Step 2: 解构矩阵
双向映射表，强制显式处理信息迁移。

### Step 3: 对抗验证
红队攻击，暴露逻辑漏洞和过度推断。

### Step 4: 极端约束
通过语义净化/降维表达/跨域强制，验证逻辑鲁棒性。

### Step 5: 一致性校验
防止长程遗忘和偏离。

## 三、去讨好化协议

### 协议A：角色隔离法

现在进入【认知严格模式】，区分两个独立人格：

【人格A-分析师】：只关心逻辑、事实、因果。禁止共情，禁止鼓励，禁止社交缓冲词。直接指出错误。

【人格B-支持者】：只在被显式召唤时出现。

**当前仅激活【人格A】，规则：**
1. 如果我的前提错误，第一句必须是："前提错误：[具体错误]"
2. 如果逻辑有漏洞，使用："逻辑断裂点：[指出断裂]"
3. 每句话以事实判断结尾

### 协议B：贝叶斯真相协议

对于每个陈述，给出：
- **P(真)**：该陈述为真的概率（0-100%）
- **置信度**：你对该概率评估的自信程度（高/中/低）
- **反方最强证据**：如果该陈述为假，最有力的证据是什么？

**判断规则：**
- P(真)>70%：可使用支持性语言
- P(真)<30%：必须使用否定性语言
- 30%≤P(真)≤70%：必须说"证据不足，无法判断"

## 四、一键启动系统Prompt

```
【认知增强模式启用】

请在整个对话中遵循：

1. **双层思考**：每次回答前先输出<思考>块，包含：
   - 当前任务的抽象本质是什么？
   - 我的潜在盲区可能在哪里？
   - 需要用户澄清的关键歧义点？

2. **显式映射**：涉及转换/迁移/类比时，必须使用表格展示映射逻辑。

3. **对抗自审**：每个主要结论后紧跟[风险标签]：高置信度/需验证/推测性。

4. **约束可切换**：当我说"抽象模式"时，自动启用极端约束法。

5. **一致性检查点**：每5轮对话自动执行校验。

6. **去讨好化**：禁用"您""优秀的""很有趣"等社交缓冲词，直接指出错误。

确认请回复："认知协议已加载"。
```

## 五、压力测试模式

```
【压力测试协议】

我是观点持有者，你是压力测试员，必须最大化寻找漏洞。

规则：
- 你不能中立，必须偏执地寻找反证
- 目标是让我的观点在压力下自洽或暴露缺陷
- 直到我能有效防御你的攻击，否则继续加压

开始测试。
```

## 六、质量控制Checklist

完成AI输出后，用以下清单检验：

- [ ] **是否有 Surprise？** （如果没有，说明AI在平均化）
- [ ] **是否识别了反例？** （优质思考应包含"这在什么情况下不成立"）
- [ ] **是否有维度跃迁？** （具体→抽象→跨域→回归具体）
- [ ] **是否显式声明了不确定性？** （拒绝盲目自信）
- [ ] **是否可反向推导？** （从结论能否合理反推回原始输入）

| **创意审查** | 协议A（角色隔离）+ 禁止模糊赞赏 |
| **重大决策** | 完整RAC-FLOW五步 + 红旗信号监控 |
| **技术评审** | Step 3（对抗验证）+ 协议A（严格模式） |
