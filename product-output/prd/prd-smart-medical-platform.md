## 1. 产品概述

### 1.1 产品背景

智慧医疗服务平台是为医院打造的综合性移动互联网医疗服务解决方案，通过整合线上线下医疗资源，为患者提供便捷的就医服务体验，提升医院服务效率。

### 1.2 产品定位

- **目标用户**: 就诊患者及其家属
- **核心价值**: 让就医更简单、更高效、更智能
- **服务范围**: 覆盖就医全流程的线上化服务

### 1.3 目标医院

平台已接入30+家医院，包括：
- 江苏省中医院
- 温医附二院就医助手
- 浙江省肿瘤医院
- 台州市第一人民医院
- 绍兴市人民医院
- 安康市中医医院
- 等等...

**已登录无就诊人：**

**已登录有就诊人：**
- 显示当前就诊人姓名、ID

## 6. 交互规范

### 6.1 页面转场

| 场景 | 动画 | 时长 |
|------|------|------|
| 页面进入 | 从右向左滑入 | 300ms |
| 页面返回 | 从左向右滑出 | 300ms |
| 弹窗出现 | 从底部滑入 + 淡入 | 250ms |
| 弹窗消失 | 向下滑出 + 淡出 | 200ms |
| 列表加载 | 骨架屏渐变 | 300ms |

### 6.2 手势操作

| 手势 | 触发场景 | 响应动作 |
|------|----------|----------|
| 点击 | 按钮、列表项 | 触发对应功能 |
| 长按 | 就诊人卡片 | 弹出操作菜单 |
| 下拉 | 列表页面 | 刷新数据 |
| 上拉 | 列表页面 | 加载更多 |
| 左滑 | 列表项 | 显示删除按钮 |

### 6.3 反馈机制

| 场景 | 反馈方式 | 说明 |
|------|----------|------|
| 操作成功 | Toast提示 + 成功图标 | 显示2秒 |
| 操作失败 | Toast提示 + 错误图标 | 显示3秒 |
| 加载中 | Loading动画 | 全局遮罩 |
| 网络异常 | 缺省页提示 | 显示重试按钮 |
| 空数据 | 空状态插画 | 引导用户操作 |
