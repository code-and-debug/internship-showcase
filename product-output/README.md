## 📄 文档清单

### 1. PRD - 产品需求文档 ([prd/](./prd/))

**文件**: `prd-smart-medical-platform.md`

**内容概览**:
- 产品概述（背景、定位、目标医院）
- 功能架构（12个核心功能模块）
- 用户流程（主流程 + 预约挂号流程）
- 页面详细设计（8个核心页面原型描述）
- 设计规范（色彩、字体、间距、圆角）
- 交互规范（转场动画、手势操作、反馈机制）
- 技术架构（Vue3 + UniApp + TypeScript）
- 安全规范（数据安全、支付安全、隐私合规）
- 性能要求（加载性能、运行性能）

**亮点**:
- 完整的医疗服务平台PRD，涵盖患者就医全流程
- 详细的设计规范和交互说明
- 多端适配方案（微信小程序、支付宝、H5、鸿蒙）

---

### 2. 原型设计 ([prototype/](./prototype/))

**文件**: `prototype-high-fidelity.html`

**说明**: 高保真交互原型文件，可浏览器打开预览

**包含页面**:
- 首页（功能导航、就诊人卡片、公告栏）
- 预约挂号（院区选择、科室选择、医生排班）
- 门诊缴费（待缴费列表、费用明细、在线支付）
- 报告查询（检验报告、检查报告、体检报告）
- 住院服务（住院信息、费用清单、预交金充值）
- 个人中心（我的订单、我的服务、我的工具）
- 就诊人管理（添加/切换就诊人）
- 智能医助（AI问诊、常见问题）
