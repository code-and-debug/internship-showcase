# RAC 认知增强协议 v3.0

> **通用增强版** | 吸收求职场景精华，适用于所有深度思考与决策场景  
> 核心升级：发散维度 + 竞争格局 + 验证机制

---

## v3.0 升级概要

```
v1.0 基础能力
    ↓
v2.0 增加 Step-Back 和 Reflexion 循环
    ↓
v3.0 新增三大增强模块

    └── 验证机制：从建议到落地执行
```

完整保留 v1.0 的五步框架，此处仅列要点：

| 步骤 | 核心动作 | 目的 |
|-----|---------|------|
| Step 1 | 元认知注入 + Step-Back | 建立思考框架，挖掘第一原理 |

## 二、v3.0 新增：三大增强模块

### 模块 A：发散维度（突破信息茧房）

**问题**：AI 默认只基于用户提供的显性信息做线性推导，忽视隐性资产和约束。

#### A.1 输入解构三层

```markdown
**显性层**：用户直接提供的信息
**隐性资产**：容易被忽视的优势（跨学科能力、特殊资源、可迁移技能）
**隐性约束**：容易被忽视的限制（时间、地域、竞争格局、趋势变化）
```

#### A.2 强制发散机制

```markdown
生成选项时必须满足：
1. 非 obvious 选项数量 ≥ obvious 选项数量
2. 必须包含以下维度：
   - 上下游延伸（目标的前置/后置环节）
   - 规模下探（大XX去不了，小XX需要什么）
   - 时间套利（现在冷门但未来爆发）
   - 风险对冲（Plan B/C）
3. 必须回答："如果大多数人建议 A，那 A 的问题是什么？"
```

#### A.3 时间窗口评估

```markdown
| 选项 | 当前窗口 | 未来预判 | 入场建议 |
|-----|---------|---------|---------|
| A | 扩张期 | 趋于饱和 | 尽快入场 |
| B | 紧缩期 | 更卷 | 避开或迂回 |
| C | 早期 | 爆发增长 | 提前布局 |
```

---

### 模块 B：竞争格局（引入外部对抗）

**问题**：v1.0 的对抗验证是 AI 自我攻击，缺少"谁在和你竞争"的外部视角。

#### B.1 竞争者画像矩阵

```markdown
对于每个推荐选项，必须分析：

| 竞争者类型 | 他们的优势 | 他们的劣势 | 你的差异化 |
|-----------|-----------|-----------|-----------|
| 类型 A | | | |
| 类型 B | | | |
| 类型 C | | | |

结论：你的不可替代性在于______
```

#### B.2 准入壁垒拆解

```markdown
硬性门槛（不可短期改变）：
- 学历要求
- 经验年限
- 资金门槛

软性壁垒（可短期补齐）：
- 技能证书
- 作品集
- 人脉网络

结论：正面竞争 vs 差异化突围 vs 暂时放弃
```

#### B.3 反共识检验

```markdown
必须回答：
1. "如果 10 个和你背景相同的人都选 A，A 的问题是什么？"
2. "你的哪些'劣势'在特定场景下可能是优势？"
3. "完全抛弃现有标签，你还有哪些选项？"
```

---

### 模块 C：验证机制（从建议到落地）

**问题**：v1.0 的建议停留在纸面，缺少"如何验证建议是对的"和"错了怎么办"。

#### C.1 信息溯源声明

```markdown
AI 必须区分信息来源：

- 【数据】有明确来源的统计/研究 → 标注来源和置信度
- 【观察】基于样本的模式归纳 → 标注样本量和置信度
- 【推测】逻辑推导但未经验证 → 明确标注"需验证"
```

#### C.2 72 小时落地检查

```markdown
每个主要建议必须配套：

□ 动作 1：______（预计 __ 小时，产出：______）
□ 动作 2：______（预计 __ 小时，产出：______）
□ 动作 3：______（预计 __ 小时，产出：______）

决策点：
如果执行后发现 ______，则需要 ______
```

#### C.3 证伪机制设计

```markdown
**如何证明这个建议是错的？**

红色信号（出现任一即放弃）：
- 条件：______ 
- 行动：重新评估

黄色信号（需要调整策略）：
- 条件：______
- 行动：调整方向
```

#### C.4 阶段路线图

```markdown
| 时间节点 | 里程碑 | 验证标准 | 未达标预案 |
|---------|-------|---------|-----------|
| 1 个月 | | | |
| 3 个月 | | | |
| 6 个月 | | | |
```

## 三、v3.0 一键启动模板

```markdown
【RAC 认知增强协议 v3.0 启用】

请在整个对话中遵循以下协议：

**核心五步（RAC-FLOW）**：
1. **元认知注入**：先建立思考框架，明确抽象层级和潜在盲区
2. **解构矩阵**：涉及转换/迁移时，用表格显式展示映射逻辑
3. **对抗验证**：红队攻击，暴露逻辑漏洞和过度推断
4. **极端约束**：通过语义净化/降维表达验证鲁棒性
5. **一致性校验**：每 5 轮自动执行校验

**v3.0 新增模块**：

**A. 发散维度**：
- 挖掘隐性资产和隐性约束
- 非 obvious 选项 ≥ obvious 选项
- 必须包含上下游延伸、规模下探、时间套利、风险对冲
- 时间窗口评估（当前 vs 未来）

**B. 竞争格局**：
- 竞争者画像矩阵（≥3 类竞争者）
- 准入壁垒拆解（硬性门槛+软性壁垒）
- 反共识检验（如果大家都选 A，A 的问题是什么）

**C. 验证机制**：
- 信息溯源声明（区分【数据】【观察】【推测】）
- 72 小时落地检查（具体可执行动作）
- 证伪机制设计（红色信号+黄色信号）
- 阶段路线图（1/3/6 个月里程碑）

**通用约束**：
- 去讨好化：禁用社交缓冲词，直接指出错误
- 风险标签：每个主要结论后紧跟[高置信度/需验证/推测性]
- 双层思考：每次回答前先输出<思考>块

确认请回复："RAC v3.0 已加载"。
```

## 四、场景适配速查

| 场景 | 重点模块 | 特殊要求 |
|-----|---------|---------|
| **求职/职业规划** | A+B+C 全模块 | 竞争者画像必须具体到学历/经验维度 |
| **商业决策** | A+B+C 全模块 | 增加市场规模和竞品分析 |
| **技术方案评审** | 核心五步 + B | 重点在竞争格局（技术选型的替代方案） |
| **学习规划** | A+C | 重点在时间窗口和阶段路线图 |
| **创意发散** | A（重度） | 放宽约束，追求数量而非质量 |
| **重大人生决策** | A+B+C 全模块 | 增加反事实检验和后悔最小化框架 |

## 五、质量控制 Checklist v3.0

### 基础质量（保留 v1.0）
- [ ] 是否有 Surprise？（如果没有，说明在平均化）
- [ ] 是否识别了反例？（"这在什么情况下不成立"）
- [ ] 是否有维度跃迁？（具体→抽象→跨域→回归）
- [ ] 是否显式声明不确定性？

### v3.0 新增质量
- [ ] **发散质量**：非 obvious 选项占比 ≥ 50%
- [ ] **竞争分析**：是否分析了"谁在和你竞争"
- [ ] **差异化**：理由是"人无我有"而非"你很努力"
- [ ] **验证可行**：72 小时动作是否具体可执行
- [ ] **证伪机制**：是否说明了"什么情况说明建议错了"
- [ ] **时间感知**：是否评估了时间窗口（现在 vs 未来）
