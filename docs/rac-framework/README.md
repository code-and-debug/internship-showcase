# RAC-FLOW 认知增强框架

> **Reflective-Adversarial-Cognitive Framework for LLM Optimization Workflow**

将 AI 从"答题器"转变为"认知协处理器"的方法论。

---

## 版本选择

| 版本 | 适用场景 | 特点 | 文档 |
|------|----------|------|------|
| **基础版** | 快速上手、日常工作 | 简洁五步模板，即开即用 | [RAC-FLOW.md](./RAC-FLOW.md) |
| **进阶版** | 深度研究、复杂决策 | 增加AI边界警示、去讨好化协议、贝叶斯机制 | [RAC-Protocol-v1.md](./RAC-Protocol-v1.md) |

**建议**：先阅读基础版掌握核心流程，进阶版在重要决策时启用。

---

## 一句话介绍

通过 **元认知注入 → 解构矩阵 → 对抗验证 → 极端约束 → 一致性检查** 五个步骤，迫使 AI 进入深度思考模式，输出高质量、可验证、可迁移的分析结果。

---

## 核心优势

| 能力 | 说明 |
|------|------|
| **防止AI平均化** | 突破AI默认的"安全但平庸"输出 |
| **显式逻辑链** | 强制展示思考过程，而非直接给结论 |
| **去讨好化** | 获取真实反馈，而非虚假赞同 |
| **跨域迁移** | 通过解构矩阵实现能力标签化迁移 |

## 与 V.A.R.C. 的关系

```
RAC-FLOW（认知层）     ← 本框架：提升 AI 思考质量
        ↓
V.A.R.C.（执行层）     ← 配套框架：治理 AI 长上下文开发
        ↓
    工程产出
```

- **RAC-FLOW** 解决"AI 怎么想得更好"
- **V.A.R.C.** 解决"AI 记得更多、不偏离"

两者结合，构成完整的 **AI 工作流方法论**。

## 快速开始

**基础版启动**：
```markdown
【认知增强模式启用】

请在整个对话中遵循以下协议：
1. 双层思考：每次回答前先输出<思考>块
2. 显式映射：使用表格展示映射逻辑
3. 对抗自审：结论后紧跟[风险标签]
4. 一致性检查：每5轮自动校验

确认请回复："认知协议已加载"。
```

**进阶版启动**：见 [RAC-Protocol-v1.md](./RAC-Protocol-v1.md) 第四节

## 质量控制

完成 AI 输出后，用以下清单快速检验：

- [ ] **是否有 Surprise？** （如果没有，说明 AI 在平均化）
- [ ] **是否识别了反例？** （优质思考应包含"这在什么情况下不成立"）
- [ ] **是否有维度跃迁？** （具体→抽象→跨域→回归具体）
- [ ] **是否显式声明了不确定性？** （拒绝盲目自信）
- [ ] **是否可反向推导？** （验证逻辑链完整性）
