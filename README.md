### 技术栈

| 技术 | 说明 | 版本 |
|------|------|------|
| Vue 3 | 渐进式框架 | ^3.3.0 |
| TypeScript | 类型安全 | ^5.0.0 |
| UniApp | 跨端框架 | ^3.99 |
| VueUse | 组合式工具 | ^10.0.0 |

### 设计原则

1. **单一职责原则 (SRP)**: 一个函数/组件只做一件事
2. **组合式函数 (Composables)**: 抽离可复用逻辑
3. **类型优先**: 全面使用 TypeScript 严格模式
4. **常量管理**: 告别魔法数字

## 💡 面试要点

### 可以重点讲的点

1. **业务复杂度处理**: 如何处理医疗系统复杂的状态流转和数据关联
2. **代码质量意识**: 主动重构，提高可维护性
3. **TypeScript 深度应用**: 不仅仅是类型标注，而是类型驱动开发
4. **性能优化**: 大列表渲染、表单校验优化
5. **跨团队协作**: 与后端、产品、测试的沟通配合

### 面试话术示例

> **面试官**: 你在实习期间最有挑战的项目是什么？

> **回答**:
> "我在实习期间负责了 4 个业务模块的开发，其中最有挑战的是**省中 MDT 问诊改造**。
>
> **业务背景**: 这是一个大型问诊流程重构，需要支持预问诊问答、图片上传、语音输入、报告生成等功能。
>
> **技术挑战**:
> 1. 原始代码 1000+ 行，混杂了 UI、业务逻辑、数据处理，维护困难
> 2. 对话式交互设计，状态管理复杂
> 3. 多种输入方式（文字、图片、语音）的统一处理
>
> **我的解决方案**:
> 1. **架构重构**: 使用 Vue 3 Composition API，将代码拆分为 3 个 Composables + 纯 UI 组件
> 2. **类型安全**: 定义了 15+ 个接口，消除所有 any 类型
> 3. **逻辑分层**: 业务逻辑、文件上传、语音输入各自独立
>
> **成果**: 代码量减少 65%，类型覆盖率 100%，获得了 mentor 的认可。"
