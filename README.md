| 模块 | 工作内容 | 技术点 |
|-----|---------|--------|
| **预约挂号** | 排班列表开发、号源选择、预约提交 | 树形数据转矩阵、双模式展示 |

## 主要解决的问题

### 1. 多医院部署问题

**问题**：一套代码要给8家医院用，每家功能不同

**解决**：配置化架构，通过 `sysCode` 控制功能开关

```typescript
// 配置示例
{
  sysCode: '1001033',
  isShowQueueNumber: true,
  isShowNetWork: false
}

// 组件中使用
<FeatureWrapper featureKey="isShowQueueNumber">
  <QueueNumber />
</FeatureWrapper>
```

### 2. 排班数据展示问题

**问题**：后端返回树形数据，前端要展示成表格

**解决**：写了一个数据转换函数，把树形结构转成矩阵

核心代码在 `02-Core-Assets/tech-articles/01-预约挂号排班算法.md`

### 3. 人脸识别状态同步

**问题**：用户扫码人脸认证，前端怎么知道成功了

**解决**：轮询机制，每4秒查一次，最多25次，配倒计时

详细实现见 `02-Core-Assets/tech-articles/02-人脸识别轮询机制.md`
