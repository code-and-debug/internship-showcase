# 和仁科技患者端项目技术沉淀

> 医疗信息化前端开发实践 | 配置化架构 | 多租户 SaaS 设计

## 📋 项目简介

本项目为杭州和仁科技股份有限公司患者端互联网医院产品的技术沉淀，涵盖预约挂号、费用管理、用药管理、智能导诊、DRG 结算等核心医疗场景。

**核心技术挑战**：
- 一套代码支持多家医院部署（多租户架构）
- 医疗数据安全与等保合规
- 复杂业务组件的模块化设计

## 📦 业务模块

| 模块 | 功能描述 | 核心实现 |
|-----|---------|---------|
| **cost-center** | 费用中心：门诊缴费、住院预交金、退款、日结查询 | 支付状态机、金额精度处理 |
| **drg-settlement** | DRG 结算：病案分组、费用分析、特案申请 | 数据可视化、复杂表单校验 |
| **medication-manager** | 用药管理：处方查询、服药提醒、依从性追踪 | 定时任务、本地存储同步 |
| **smart-pre-diagnosis** | 智能预问诊：症状选择、人体图导诊、评估报告 | 树形数据转换、Canvas 人体图 |
| **questionnaire-refactor** | 表单引擎：动态问卷、健康评估 | 动态组件渲染、条件逻辑 |
| **mdt-inquiry** | 多学科会诊：专家预约、病历资料上传 | 文件上传、流程状态管理 |
| **hospital-butler** | 住院管家：住院清单、护理记录、费用明细 | 长列表优化、数据缓存 |
| **treatment-appointment** | 治疗预约：检查/检验/治疗预约 | 日历组件、时段冲突检测 |

### 配置化架构核心代码

```typescript
// 功能开关组件
<FeatureWrapper featureKey="isShowQueueNumber">
  <QueueNumberCard />
</FeatureWrapper>

// 配置驱动路由
{
  path: 'hmfw/queueNumber',
  component: () => import('@/pages/QueueNumber'),
  meta: {
    feature: 'isShowQueueNumber',  // 通过配置控制显示
  }
}
```
