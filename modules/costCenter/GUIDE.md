## 功能说明

### 1. 费用首页

**入口**: `/pagesD/costCenter/index`

**功能**:
- 展示账户余额、已缴金额、押金
- 显示费用状态（充足/不足/欠费）
- 提供功能入口卡片

**数据加载**:
```typescript
const { loadCostInfo } = useCost();
await loadCostInfo(patientId);
```

### 2. 费用明细

**入口**: `/pagesD/costCenter/detail`

**功能**:
- 按日期筛选
- 按分类筛选（药品/检查/治疗等）
- 分页加载明细列表

**参数**:
```typescript
await store.fetchDetailList({
  admissionNo: '住院号',
  date: '2024-01-01',      // 可选
  category: '药品',         // 可选
  page: 1,
  size: 10
});
```

### 3. 日清单

**入口**: `/pagesD/costCenter/daily`

**功能**:
- 选择特定日期
- 查看当日所有费用明细
- 当日费用合计

### 4. 在线缴费

**入口**: `/pagesD/costCenter/pay`

**流程**:
```
1. 输入充值金额 或 选择快捷金额
2. 选择支付方式（微信/支付宝）
3. 点击确认支付
4. 创建支付订单
5. 发起支付（调用SDK）
6. 轮询支付结果
7. 支付成功后刷新费用信息
```

**支付状态**:
- `pending` - 待支付
- `paid` - 已支付
- `failed` - 支付失败

### 5. 退费申请

**入口**: `/pagesD/costCenter/refund`

**流程**:
```
1. 系统计算可退金额
2. 用户填写退费原因
3. 提交退费申请
4. 后台审核处理
5. 原路返回至支付账户
```

**退费状态**:
- `pending` - 待处理
- `processing` - 处理中
- `completed` - 已完成
- `rejected` - 已拒绝

### 6. 缴费记录

**入口**: `/pagesD/costCenter/records`

**功能**:
- 查看历史缴费记录
- 查看退费记录
- 查看订单状态

## 费用状态说明

| 状态码 | 状态名 | 含义 | 建议操作 |
|--------|--------|------|----------|
| 1 | BALANCE | 余额充足 | 正常就医 |
| 2 | WARNING | 余额不足 | 建议充值 |
| 3 | ARREARS | 已欠费 | 立即充值 |

## 常见问题

### Q1: 支付失败怎么办？
A: 检查网络连接，确认支付账户余额充足，或稍后重试。

### Q2: 退费需要多长时间？
A: 一般1-3个工作日处理，原路返回至支付账户。

### Q3: 可以退已使用的费用吗？
A: 退费金额 = 已缴金额 - 已使用费用，不可退已使用部分。

### Q4: 如何查看费用明细？
A: 进入"费用明细"页面，可按日期和分类筛选。
