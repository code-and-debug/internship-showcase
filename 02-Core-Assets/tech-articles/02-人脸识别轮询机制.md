# 人脸识别 + 长轮询机制实现方案

## 一、业务场景

医疗系统添加就诊人需要实名认证，对于18-60岁用户，系统要求进行人脸识别。流程如下：

1. 用户填写就诊人信息
2. 系统生成二维码
3. 用户微信扫码进行人脸识别
4. 识别成功后自动添加就诊人

**技术挑战**：
- 需要**异步等待**人脸识别结果（可能持续几十秒）
- 需要**超时控制**（防止无限等待）
- 需要**状态同步**（识别成功后更新列表）

## 二、整体架构

```
用户填写表单 → 后端生成签名 → 前端生成二维码 → 用户扫码 → 人脸识别 → 后端更新数据 → 前端轮询检测到 → 添加成功
```

## 三、核心实现

### 3.1 自定义useInterval Hook

```javascript
// hooks/useInterval.js
import { useEffect, useRef } from 'react';

/**
 * 自定义定时器Hook，支持动态启停
 * @param {Function} callback - 回调函数
 * @param {number|null} delay - 延迟时间（ms），null时停止
 */
export default function useInterval(callback, delay) {
  const savedCallback = useRef();

  // 保存最新的回调函数引用
  useEffect(() => {
    savedCallback.current = callback;
  }, [callback]);

  // 设置定时器
  useEffect(() => {
    function tick() {
      savedCallback.current();
    }
    if (delay !== null) {
      const id = setInterval(tick, delay);
      return () => clearInterval(id); // 清理函数
    }
  }, [delay]);
}
```

### 3.2 主组件实现

```javascript
import React, { useState, useCallback } from 'react';
import { Form, Input, Button, Modal, Spin, message } from 'antd';
import { QRCodeSVG } from 'qrcode.react';
import useInterval from '@/hooks/useInterval';
import { getPatCardList, cachePat, addPat } from '@/services/user';
import { getInfoFromIdCard } from '@/utils/utils';
import dayjs from 'dayjs';

const AddSickPerson = (props) => {
  const { global, user, sysCode, herenId, dispatch } = props;
  const [form] = Form.useForm();
  
  // ===== 核心状态 =====
  const [qrModalVisible, setQrModalVisible] = useState(false);      // 二维码弹窗
  const [qrCodeUrl, setQrCodeUrl] = useState('');                   // 二维码URL
  const [qrCodeLoading, setQrCodeLoading] = useState(false);        // 生成中状态
  const [pollingInterval, setPollingInterval] = useState(null);     // 轮询定时器
  const [timeoutCount, setTimeoutCount] = useState(60);             // 倒计时（秒）
  
  // ===== 提交处理 =====
  const onFinish = async (values) => {
    try {
      // 判断是否需要人脸识别：18-60岁且为中国身份证
      const userAge = getInfoFromIdCard(values.idCard).age;
      const needFaceCheck = (
        global.isAddPatFace === '1' && 
        values.idType === '01' &&
        userAge > 17 && 
        userAge < 60
      );
      
      if (needFaceCheck) {
        await faceData(values); // 走人脸识别流程
      } else {
        await addpatFun(values); // 直接添加
      }
    } catch (error) {
      message.error('操作失败：' + error.message);
    }
  };
  
  // ===== 人脸识别流程 =====
  const faceData = async (values) => {
    // 构造请求参数
    const data = {
      ...values,
      patientType: 1,
      patientName: values.name,
      patientPhone: values.mobile,
      defaultFalg: values.defaultFalg ? 1 : 0,
      psnId: herenId,
      birthday: dayjs(values.birthday).format('YYYY-MM-DD'),
      sysCode: sysCode,
      verifyType: values.verifyCode ? '2&kq' : '1&bk',
      source: '5',
      address: values.address?.join(''),
    };
    
    setQrCodeLoading(true);
    setQrModalVisible(true);
    setTimeoutCount(60);
    
    try {
      // 1. 请求后端生成签名
      const res = await cachePat(data);
      if (res.code == 0) {
        // 2. 生成二维码URL
        const qrUrl = `https://h5.eheren.com/scan/${sysCode}/addPatByScan?` + 
          `name=${encodeURIComponent(values.name)}&` +
          `idCard=${values.idCard}&` +
          `source=5&` +
          `sign=${res.result}`;
        
        setQrCodeUrl(qrUrl);
        
        // 3. 开始轮询和倒计时
        pollFaceResult(values.name);
      } else {
        message.error(res.message);
        setQrModalVisible(false);
      }
    } finally {
      setQrCodeLoading(false);
    }
  };
  
  // ===== 核心轮询逻辑 =====
  const pollFaceResult = (targetName) => {
    let attempt = 0;
    const maxAttempts = 25; // 最大轮询25次（100秒）
    
    const interval = setInterval(async () => {
      attempt++;
      
      try {
        // 轮询：查询就诊人列表
        const res = await getPatCardList({
          sysCode: sysCode,
          psnId: herenId,
        });
        
        if (res?.code == '0' && Array.isArray(res.result)) {
          // 检查是否包含目标就诊人（识别成功）
          const matchedPatient = res.result.find(
            (patient) => patient.patientName === targetName
          );
          
          if (matchedPatient) {
            // ✅ 识别成功
            clearInterval(interval);
            message.success('识别成功，就诊人已添加');
            setQrModalVisible(false);
            form.resetFields();
            
            // 更新就诊人列表
            dispatch({
              type: 'user/savePatCardList',
              payload: res.result,
            });
            return;
          }
          
          // ❌ 超过最大次数，超时
          if (attempt >= maxAttempts) {
            clearInterval(interval);
            message.warning('人脸识别超时，请重新尝试');
            setQrModalVisible(false);
          }
        }
      } catch (error) {
        clearInterval(interval);
        message.error('网络异常，请重试');
        setQrModalVisible(false);
      }
    }, 4000); // 每4秒轮询一次
    
    setPollingInterval(interval);
  };
  
  // ===== 直接添加（非人脸识别）=====
  const addpatFun = async (values) => {
    const data = { ...values, patientType: 1 };
    const res = await addPat(data);
    
    if (res.code == '0') {
      message.success('添加成功');
      // 刷新列表
      dispatch({
        type: 'user/fetchPatCardList',
        payload: { sysCode, psnId: herenId },
      });
    } else {
      message.error(res.message);
    }
  };
  
  // ===== 倒计时Hook =====
  useInterval(() => {
    setTimeoutCount((prev) => {
      const newCount = prev - 1;
      if (newCount <= 0) {
        setQrModalVisible(false);
        message.warning('人脸识别超时');
        // 清理轮询
        if (pollingInterval) {
          clearInterval(pollingInterval);
        }
      }
      return newCount;
    });
  }, qrModalVisible ? 1000 : null);
  
  // ===== 关闭弹窗时清理 =====
  const handleCancel = () => {
    setQrModalVisible(false);
    if (pollingInterval) {
      clearInterval(pollingInterval);
      setPollingInterval(null);
    }
  };
  
  return (
    <div>
      <Form form={form} onFinish={onFinish}>
        {/* 表单字段... */}
        <Form.Item>
          <Button type="primary" htmlType="submit">
            提交
          </Button>
        </Form.Item>
      </Form>
      
      {/* 二维码弹窗 */}
      <Modal
        title="人脸识别二维码"
        visible={qrModalVisible}
        onCancel={handleCancel}
        footer={null}
        centered
        maskClosable={false} // 防止误关闭
      >
        <div style={{ textAlign: 'center', padding: '24px' }}>
          {qrCodeLoading ? (
            <Spin size="large" tip="生成中..." />
          ) : (
            <>
              <QRCodeSVG value={qrCodeUrl} size={160} level="H" />
              <div style={{ marginTop: '16px', color: '#999' }}>
                剩余时间：<span style={{ color: '#f5222d' }}>{timeoutCount}</span> 秒
              </div>
              <div style={{ marginTop: '16px', color: '#666' }}>
                请使用微信扫一扫完成人脸识别
              </div>
            </>
          )}
        </div>
      </Modal>
    </div>
  );
};

export default AddSickPerson;
```

## 四、关键技术解析

### 4.1 长轮询 vs WebSocket vs SSE

| 方案 | 适用场景 | 优缺点 |
|-----|---------|-------|
| **长轮询** | 低频事件（如人脸识别） | 实现简单，兼容性好，但有延迟 |
| WebSocket | 高频实时通信 | 实时性好，但维护成本高 |
| SSE | 服务器推送 | 单向通信，适合通知类场景 |

**为什么选择长轮询**：
- 人脸识别是**一次性事件**，不需要持续连接
- 需要兼容老旧浏览器
- 实现简单，不依赖额外服务

### 4.2 竞态条件处理

```javascript
// 问题：组件卸载时定时器还在运行，导致内存泄漏

  return () => clearInterval(interval);

const isMounted = useRef(true);

  return () => { isMounted.current = false; };
```

```javascript
const pollWithRetry = async (targetName, maxRetry = 3) => {
  let retryCount = 0;

    try {
      const res = await getPatCardList({...});
```

## 六、性能优化

### 6.1 轮询间隔优化

```javascript
// 指数退避策略（逐渐增大间隔）
const getInterval = (attempt) => {
  if (attempt < 5) return 2000;  // 前5次2秒
  if (attempt < 15) return 4000; // 中间10次4秒
  return 6000;                    // 之后6秒
};

// 使用
setTimeout(async function tick() {
  // ...轮询逻辑
  setTimeout(tick, getInterval(attempt));
}, getInterval(0));
```

### 6.2 请求合并

```javascript
// 使用防抖避免重复请求
import { debounce } from 'lodash';

const debouncedPoll = debounce(async () => {
  const res = await getPatCardList({...});
}, 1000);
```

## 八、面试话术

**Q: 人脸识别是怎么实现的？**

> "我们采用的是**轮询机制**实现人脸识别状态同步。流程是：
> 1. 用户提交信息后，后端生成带签名的二维码
> 2. 前端展示二维码，用户微信扫码进入H5人脸识别
> 3. 前端启动**定时轮询**（每4秒查询一次就诊人列表）
> 4. 检测到新就诊人后，自动停止轮询并提示成功
>
> **技术难点**在于状态同步和竞态条件处理：
> - 需要处理**超时场景**（设置25次最大轮询 + 60秒倒计时双保险）
> - 需要处理**组件卸载**时的定时器清理（useEffect返回清理函数）
> - 需要处理**网络异常**的降级策略
>
> 为什么没有选择WebSocket？因为人脸识别是一次性事件，轮询实现更简单，且兼容性好。"

**Q: 如果轮询对服务器压力大怎么优化？**

> "可以从几个维度优化：
> 1. **指数退避**：前期2秒一次，逐渐延长到6秒，减少无效请求
> 2. **请求合并**：使用防抖避免重复请求
> 3. **服务端缓存**：轮询时先读缓存，减少数据库压力
> 4. **长轮询优化**：服务端hold住请求30秒，有结果立即返回"
