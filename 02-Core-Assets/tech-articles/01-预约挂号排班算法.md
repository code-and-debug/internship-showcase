# 预约挂号排班算法 - 多维数据转换方案

## 一、业务场景

医院预约挂号系统需要支持两种展示模式：
1. **按日期排班**：横向为日期（未来7天），纵向为时间段（上午/下午），单元格显示可预约医生
2. **按医生排班**：横向为日期，纵向为医生列表，单元格显示该医生当日可预约状态

后端返回的是**树形嵌套结构**，前端需要转换为**矩阵表格结构**。

## 三、核心算法实现

### 3.1 数据转换主函数

```javascript
/**
 * 将树形排班数据转换为矩阵结构
 * @param {Object} val - 后端返回的原始数据
 * @returns {Array} - 矩阵数组，可直接用于Ant Design Table
 */
function resolveData(val) {
  // 第一步：提取基础数据结构
  const [dataSource, time] = transData(val);
  
  // 第二步：按时间段分类数据
  for (const timeKey in time) {
    for (const dataSourceKey in dataSource) {
      dataSource[dataSourceKey].forEach((i) => {
        if (timeKey == i.ampmName) {
          time[timeKey].push(i);
        }
      });
    }
  }
  
  // 第三步：按日期二次分组
  const resultObj = {};
  Object.keys(time).forEach((i) => {
    resultObj[i] = {};
  });
  
  for (const timeKey in time) {
    time[timeKey].forEach((i) => {
      if (i.schDate in resultObj[timeKey]) {
        resultObj[timeKey][i.schDate].push(i);
      } else {
        resultObj[timeKey][i.schDate] = [i];
      }
    });
  }
  
  // 第四步：转换为数组结构
  const resultArr = [];
  for (const resultObjKey in resultObj) {
    resultArr.push({
      ampmName: resultObjKey,
      ...resultObj[resultObjKey],
    });
  }
  
  // 第五步：排序（上午在前，下午在后）
  if (resultArr[0]?.ampmName == '下午') {
    resultArr.reverse();
  }
  
  return resultArr;
}
```

### 3.2 基础数据提取

```javascript
/**
 * 提取日期和时间段基础结构
 * @param {Object} data - 原始数据
 * @returns {Array} - [按日期分组的数据, 时间段模板]
 */
function transData(data) {
  const tempObj = {};
  const timePointObj = {};
  
  if (data.dataList && data.dataList.length > 0) {
    data.dataList.forEach((pre) => {
      pre.schDateList.forEach((i) => {
        i.schemeList.forEach((j) => {
          j.schemeList.forEach((w) => {
            // 按日期分组
            if (i.schDate in tempObj) {
              tempObj[i.schDate].push(w);
            } else {
              tempObj[i.schDate] = [w];
            }
            // 收集时间段类型
            timePointObj[w.ampmName] = [];
          });
        });
      });
    });
  }
  return [tempObj, timePointObj];
}
```

### 3.3 按医生排班的数据转换

```javascript
/**
 * 医生维度的排班数据转换
 * @param {Array} data - 医生排班原始数据
 * @returns {Array} - 医生矩阵数据
 */
const transDataForDocSch = (data) => {
  if (data.length > 0) {
    // 第一步：扁平化处理
    let flattened = data.reduce((pre, cur) => {
      cur.schDocAmPm?.map((item) => {
        item[cur.schDate] = cur.schState === '0' ? '可预约' : '';
        item.amPmResults?.map((tem) => {
          pre.push(tem);
        });
      });
      return pre;
    }, []);
    
    // 第二步：按上下午分组
    let morningList = flattened.filter((i) => i.ampm == '1');
    let afternoonList = flattened.filter((i) => i.ampm == '2');
    
    // 第三步：对象归约，生成日期为key的结构
    let morningObj = morningList.reduce((pre, cur) => {
      pre[cur.schDate] = [cur];
      pre.ampmName = cur.ampmName;
      pre.schState = cur.schState;
      return pre;
    }, {});
    
    let afternoonObj = afternoonList.reduce((pre, cur) => {
      pre[cur.schDate] = [cur];
      pre.ampmName = cur.ampmName;
      pre.schState = cur.schState;
      return pre;
    }, {});
    
    return [morningObj, afternoonObj];
  }
  return [];
};
```

## 五、关键技术点

### 5.1 时间复杂度分析

| 步骤 | 复杂度 | 说明 |
|-----|-------|------|
| 数据提取 | O(n) | 单层遍历树形数据 |
| 时间分类 | O(n²) | 双循环匹配时间段 |
| 日期分组 | O(n) | 单层遍历归类 |
| 总体 | O(n²) | n为号源数量，通常<1000，性能可接受 |

## 六、常见问题

### Q1: 数据转换后顺序错乱？
**解决**：对象遍历key的顺序不确定，需要显式排序：
```javascript
const sortedKeys = Object.keys(resultObj).sort((a, b) => {
  // 上午排在下午前面
  const order = { '上午': 1, '下午': 2, '晚上': 3 };
  return order[a] - order[b];
});
```

### Q2: 跨天号源如何处理？
**解决**：在transData阶段将号源按日期分组时，需要处理跨天排班：
```javascript
// 添加日期偏移标识
if (w.crossDay) {
  w.schDate = dayjs(w.schDate).add(1, 'day').format('YYYY-MM-DD');
}
```

## 七、面试话术

**Q: 你们预约挂号是怎么实现的？**

> "我们系统支持两种预约模式：按日期和按医生。核心难点在于**数据结构转换**——后端返回的是树形结构（科室→日期→时间段→号源），但前端需要矩阵展示（日期×时间段）。
>
> 我设计了一个**三层转换管道**：
> 1. **提取层**：遍历树形数据，按日期提取所有号源
> 2. **分类层**：按时间段（上午/下午）二次分组
> 3. **矩阵层**：将分组结果转为表格可用的数组结构
>
> 整个转换过程用 `reduce` 实现，时间复杂度O(n²)。为了优化性能，我使用了 `useMemo` 缓存转换结果，避免重复计算。另外还实现了周切换功能，支持查看未来14天的排班。"
